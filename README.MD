# Classic Reads

Classic Reads is a premium frontend project for discovering literary classics through a polished, accessible, and interactive catalog experience.

## Features

- Premium landing page design
- Dynamic catalog loaded from JSON
- Real `.webp` book covers
- Search by title or author
- Filter by genre
- Sort by title or year
- Favorites with localStorage
- Dark / light mode
- Accessible modal with focus management
- Pagination
- Skeleton loading
- Animated stats
- Newsletter form validation
- FAQ section
- Responsive layout

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- JSON

## Notes

Run this project using a local server because the catalog data is loaded with `fetch()`.

Examples:

- Live Server (VS Code)
- `npx serve`
- `python -m http.server`
